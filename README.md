# Venture-capital-tracker-
An AI-assisted venture capital investment research dashboard designed to track startups, funding rounds, investors, and industry trends. Built using Claude and ChatGPT to streamline startup data organization, investment analysis, and deal sourcing.

See [project setup, tests, and deployment instructions](vc-investment-tracker-web/README.md).

For Vercel, select `vc-investment-tracker-web` as the Root Directory.
